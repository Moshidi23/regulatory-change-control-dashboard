Regulatory Change Control Dashboard

Project Overview
This project demonstrates the development of an interactive Power BI dashboard used to monitor change control activities and support regulatory and quality management reporting.

The dashboard provides visibility of change control performance through KPI monitoring, workload analysis, due date tracking, and lifecycle status reporting.

To protect confidential business information, all data has been anonymized.

Business Problem
Regulatory and quality teams often manage a large number of active change controls across multiple departments.

Without effective reporting, it can be difficult to:
Monitor overdue activities
Track workload distribution
Identify process bottlenecks
Prioritize high-risk actions
Provide timely updates to stakeholders

Objective
Develop an interactive dashboard to:
Monitor open change controls
Track overdue actions
Analyse departmental workload
Visualise lifecycle status distribution
Support data-driven decision making
